# 344. Reverse String

- **Problem Link:** [LeetCode - 344. Reverse String](https://leetcode.com/problems/reverse-string/)
- **Difficulty:** 🟢 Easy
- **Topics:** Two Pointers, String

---

## 📝 Problem Statement

Write a function that reverses a string. The input string is given as an array of characters `s`.

You must do this by modifying the input array **in-place** with $O(1)$ extra memory.

---

## 💻 Solution

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        left = 0
        right = len(s) - 1
        while left < right:
            s[left],s[right] = s[right],s[left]
            left = left + 1
            right = right - 1
```

## ⏱️ Complexity Analysis

* **Time Complexity:** $O(n)$  
  We perform $n/2$ swaps across an array of length $n$, visiting each element once.

* **Space Complexity:** $O(1)$  
  The string is reversed completely in-place without using any additional arrays or data structures.

---

## 💡 Key Takeaways & Intuition

## 💡 Key Takeaways & Intuition

* **Opposites-Attract Two Pointers:**  
  I set `left = 0` and `right = len(s) - 1`. By swapping elements at both ends and stepping inward, I could reverse the string effectively until the pointers met in the middle.

* **In-Place Modification:**  
  To satisfy the strict $O(1)$ space constraint, I modified the original list directly using Python's tuple swapping (`s[left], s[right] = s[right], s[left]`) rather than creating a new string or array.
